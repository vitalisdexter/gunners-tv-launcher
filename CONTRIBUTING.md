# Contributing

Keep changes focused. Use Java 17 and the checked-in wrapper. Run unit tests, lint and both APK variants before proposing a change. Add regression tests for confirmed defects; do not rewrite the UI framework for tidiness. Preserve existing notices and asset provenance. Never commit device addresses, keys, provider payloads, watch history or personal screenshots. CI has read-only permissions and does not publish or sign releases. Hardware-dependent claims require actual device evidence and explicit owner approval.
